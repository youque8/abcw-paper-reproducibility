# Provenance / 来歴

## English
This package was assembled from the experiment archives used during the ABCW paper reconstruction. Original historical scripts are preserved under `archive/original_scripts/`. The exact-partition certificate and conflict data come from the archived exact-692 experiment. The final English manuscript is `paper/ABCW_paper_EN_master_v1.1.md`; the prior Japanese master is preserved under `archive/original_docs/ABCW_paper_master_v0.4_ja.md`.

Some historical scripts used absolute `/mnt/data/...` paths. GitHub-facing scripts in `experiments/` were normalized to repository-relative paths. The original versions are retained separately for auditability.

## 日本語
本パッケージは、ABCW論文再構成時に使用した実験アーカイブから組み直したものです。歴史的な元スクリプトは `archive/original_scripts/` に保存しています。厳密692分割の証明書とconflict dataはexact-692実験アーカイブ、最終英語本文は `paper/ABCW_paper_EN_master_v1.1.md`、従来の日本語masterは `archive/original_docs/ABCW_paper_master_v0.4_ja.md` に保存しています。

過去のスクリプトには `/mnt/data/...` の絶対パスを含むものがあったため、GitHub公開用の `experiments/` では相対パスへ正規化しました。監査可能性のため、元版は別途残しています。
