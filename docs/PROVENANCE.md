# Provenance / 来歴

## English
This package was assembled from the experiment archives used during the ABCW paper reconstruction. Original historical scripts are preserved under `archive/original_scripts/`. The exact-partition certificate and conflict data come from the archived exact-692 experiment. The master manuscript and figures come from `ABCW_paper_master_v0.4`.

Some historical scripts used absolute `/mnt/data/...` paths. GitHub-facing scripts in `experiments/` were normalized to repository-relative paths. The original versions are retained separately for auditability.

## 日本語
本パッケージは、ABCW論文再構成時に使用した実験アーカイブから組み直したものです。歴史的な元スクリプトは `archive/original_scripts/` に保存しています。厳密692分割の証明書とconflict dataはexact-692実験アーカイブ、論文本文と図は `ABCW_paper_master_v0.4` を出典とします。

過去のスクリプトには `/mnt/data/...` の絶対パスを含むものがあったため、GitHub公開用の `experiments/` では相対パスへ正規化しました。監査可能性のため、元版は別途残しています。
