- 最大クラスサイズ65
- 625アンカー未来群中575群は追加分割不要、50群のみ追加分割

- 非アンカー証人行動30個

- 361辺をすべて覆う最小証人行動数も15
- Hamming距離1でも衝突例、距離20でも同一クラス例
- 692を「行動条件に対する未来応答を保存する最小予測同値類」と解釈
