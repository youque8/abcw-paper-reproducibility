# ABCW 力学的最小予測分割 — 厳密確定

## 結論

今回の Ch07 由来 56,536 遷移、2,562 種類の到達場に対して、field-only 観測 `B(ΔW)` を用い、

`(a_t, B(ΔW_t)) -> ΔW_(t+1)`

を 100% 一価に保つための最小クラス数は **692** である。

- 異なる場: 2,562
- 厳密最小クラス数: 692
- 真の ΔW 圧縮率: 72.989852%
- 完全な `(a,ΔW)` 観測状態: 11,202
- 最小分割後の `(a,B(ΔW))` 観測状態: 8,084
- 観測状態削減率: 27.834315%
- 非決定観測状態: 0

## 厳密性の証明

### 1. 上限 692

前回の DSATUR 構成により、衝突グラフを 692 色で彩色できることを直接確認済みである。
したがって最小クラス数 χ は `χ <= 692`。

### 2. 下限 692

アンカー行動 `a = -----` を固定する。この行動で観測された場は 1,239 種類で、次場は 625 種類存在する。
異なる次場を持つ二つの場は、この同じ行動の下で必ず異なる未来へ進むため、同一クラスにできない。
したがって625個の未来群は互いに完全に衝突する。

ただし同じアンカー次場を持つ場同士でも、別の行動の下で異なる次場へ進む場合がある。
そこで625個の各未来群について、その群内部の衝突グラフの彩色数を厳密に求めた。

- アンカー未来群数: 625
- 内部衝突を持つ群: 50
- 各群で必要な追加色の総数: 67
- 各群の厳密彩色数の総和: 692

異なるアンカー未来群の頂点同士はすべて衝突するため、これらの群の彩色数は加算される。
よって `χ >= 692`。

### 3. 上下界の一致

`692 <= χ <= 692` より、

**χ = 692**。

したがって、今回の有限到達集合上では、100% の一歩先完全場予測を保つ field-only 観測の真の最小分割は 692 クラスである。

## 解釈

既存9特徴511候補では「真の ΔW 圧縮 + 100%予測」は見つからなかったが、力学から直接同値類を構成すると 2,562 -> 692 まで圧縮できる。
したがって失敗していたのは圧縮可能性そのものではなく、既存特徴量族による表現である。

この結論は今回の Ch07 到達集合・一歩先の完全場予測という目的に限定され、ABCW 一般の定理ではない。
